## Overview

Built a multimodal AI system designed to assist visually impaired users by combining object recognition, depth estimation, and OCR capabilities.

---

## Key Contributions

- **Synthetic Dataset**: Generated a comprehensive dataset of scene–query pairs covering diverse real-world scenarios and edge cases
- **Intent Classification**: Trained an embedding-based intent classifier to map user inquiries to appropriate visual or generative tasks
- **Response Generation**: Fine-tuned a BART model for context-aware verbal response generation
- **Fallback Mechanism**: Integrated an LLM-powered agent to dynamically handle out-of-scope or unplanned tasks
