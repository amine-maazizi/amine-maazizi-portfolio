## Overview

Created an interpreted imperative programming language with a complete implementation stack from lexer to interpreter. The language follows a traditional interpreter pipeline with tokenization, parsing into an AST, and tree-walking interpretation, enhanced with modern ML-based developer tooling.

[GitHub Repository](https://github.com/amine-maazizi/SagaLang)

This project extends beyond concepts from [Crafting Interpreters](https://craftinginterpreters.com/) by Robert Nystrom

---

## Key Features

- **Language Implementation**: Built a custom lexer, parser, and interpreter entirely in Python
- **Standard Library**: Developed a standard library supporting real-time graphics capabilities
- **AI-Powered Completion**: Integrated neural code completion using transformer models for intelligent suggestions
