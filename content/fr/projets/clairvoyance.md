## Présentation

Système IA multimodal conçu pour assister les personnes malvoyantes en combinant reconnaissance d'objets, estimation de profondeur et OCR.

---

## Contributions Principales

- **Dataset Synthétique** : Génération d'un dataset complet de paires scène-requête couvrant divers scénarios réels
- **Classification d'Intention** : Entraînement d'un classifieur d'intention basé sur les embeddings pour router les requêtes utilisateur
- **Génération de Réponses** : Fine-tuning d'un modèle BART pour la génération de réponses verbales contextuelles
- **Mécanisme de Fallback** : Intégration d'un agent LLM pour gérer dynamiquement les tâches hors-scope

### Technologies

`PyTorch` `HuggingFace Transformers` `BART` `Vision par Ordinateur` `OCR` `Estimation de Profondeur`
